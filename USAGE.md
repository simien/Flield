# Using Flield

The full guide lives at **[flield.com/guide](https://flield.com/guide/)**.

It moved there so it could show the interface instead of describing it. The
controls appear inline with the icons they carry in the app, and each of the
six motions plays beside the paragraph explaining it. A second copy here
would only drift, so this file points at the one that stays current.

The guide covers:

- **The basics.** Three colors, two seeded layers, and why a fresh page load keeps its background, block size, and shape mask.
- **Using the controls.** What each tab holds, how the layout rearranges into a bottom bar and sheet on a phone, and what hold-to-confirm means.
- **Texture.** Six ways to draw one field, from dithered bands to topographic contours to particle trails, and the sliders that change name between them.
- **Locks.** Holding a field's value through a randomize pass, and which three start locked.
- **Tiling without a seam.** What the Tile preset changes, and why it locks what it locks.
- **Saving and sharing.** Browser slots against shareable links, including the link that offers Auto-randomize on open.
- **Keyboard shortcuts.** R, Space, and Undo.
- **Exploring with Auto-randomize.** Locking down an art direction, then letting the rest drift.
- **Motion.** Loop, Drift, Wind, Pulse, Ripple, and Tide, each with an example clip, and the Speed slider that sets a cycle, kept apart from the Auto-randomize interval.
- **Palette Range and Density Range.** Constraining how far a randomized value can wander.
- **Rights to what you export.** The images are yours to use commercially. The code's own license is a separate matter.

The same walkthrough is built into the app, behind the **?** button. That is
a thirteen-step tutorial with a live example at every step.
